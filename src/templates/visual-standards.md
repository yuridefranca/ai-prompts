# Template: Visual Document Standards

**Slice**: 2
**Used by**: every artifact and template in `src/`

Markdown-native visual patterns only — universally renderable, no custom tooling.

## Element reference

| Element | Format | Where used |
|---|---|---|
| Machine state | YAML frontmatter (`status`, `tier`, `phase`) | `INDEX.md`, every artifact — see [artifact-status.md](../schemas/artifact-status.md), [index-frontmatter.md](../schemas/index-frontmatter.md) |
| Status tracking | `[🟡 IN PROGRESS]` `[✅ COMPLETE]` `[⛔ GATED]` badges | `INDEX.md`, every artifact header |
| Progress through flow | Mermaid flowchart with phase statuses | `INDEX.md` |
| Decisions needing input | `> ⚠️ **DECISION NEEDED**` blockquote with options | Gate packets, task reviews |
| Layer 2 detail | `<details><summary>📊 Full detail</summary>` collapsible | All artifacts — see [artifact-template.md](artifact-template.md) |
| Architecture / data flow | Mermaid diagrams (`graph TD`, `sequenceDiagram`, `stateDiagram-v2`) | 3.1, 3.2, 5-contract |
| Comparisons / tradeoffs | Structured tables with ✅⚠️❌ status column | 3.4, reviews, QA |
| Comprehension checks | `┌ CHECKS` box format | All outputs |
| ADRs | Decision table: Aspect × Option columns, ✅ on chosen | 3.4, 6.0 |
| Acceptance criteria | Table: `AC*` ID \| Status \| Evidence | 7 (review) |
| Contract clauses | Table: `C*` ID \| Clause \| Kind \| Level \| Red evidence; cited in test names | 5, 6.x, 7 — see [contract-ids.md](../schemas/contract-ids.md) |
| Findings | Table: `F*` ID \| Severity \| Found at \| Status \| Evidence | `FINDINGS.md` — see [findings.md](../schemas/findings.md) |
| QA scenarios | Numbered, tagged happy-path/edge-case/error-case/adversarial/hostile-user + coverage summary + finding-coverage table | `8-qa-plan.md` |

## Symbol vocabulary (canonical, do not invent alternates)

| Symbol | Meaning |
|---|---|
| ⛔ | Gate (requires approval) |
| ⚠️ | Deviation / flag |
| ✅ | As-planned / passed |
| ❓ | Open question |
| 🔴 | High severity |
| 🔵 | Low severity |
| 🟡 | In progress |
| ⬜ | Pending / not started |

## Fence rule

**Any template containing a fenced code block must itself be fenced with four backticks.** Three-backtick fences nested inside three-backtick fences terminate early and break rendering for everything after them. Every template in `src/templates/` that contains an example fence follows this rule — check new templates against it before landing them.

## NOT used, and why

| Excluded | Reason |
|---|---|
| ASCII art boxes | Break on different screen widths |
| Custom HTML/CSS | Not renderable in all markdown viewers |
| Images/screenshots | Can't be generated by subagents, can't be diffed |
| PDF/HTML exports | Adds tooling complexity; markdown is the universal format here |
