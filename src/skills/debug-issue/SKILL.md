# Debug Issue

This skill is designed to help you debug an issue in the codebase by deeply analyzing the problem and identifying the root cause. When a user reports a bug or an issue that needs to be investigated, you can use this skill to systematically analyze the code, identify potential causes of the issue, and provide a detailed explanation of the debugging process and the steps taken to resolve the problem.

When you want to debug an issue, follow these steps:

1. Gather information about the issue, including any error messages, logs, or user reports that can provide insights into the problem.
2. Identify the related feature or components that may be affected by the issue. This can help narrow down the areas of the codebase to focus on during debugging.
3. Review the relevant code sections, looking for any potential bugs, logical errors, or inconsistencies that could be causing the issue. Pay attention to any recent changes or updates that may have introduced the problem.
4. Use debugging techniques to further investigate the issue and gather more information about the execution flow and state of the application.
5. Formulate hypotheses about the potential causes of the issue based on your analysis and testing. Test these hypotheses by making changes to the code or configuration and observing the results.
6. Once you have identified the root cause of the issue, report to the user your findings, including a detailed explanation of the debugging process, the steps taken to identify the problem, and the solution implemented to resolve it.
7. After you found the root cause, critically analyze if there are no hidden issues that could be related to the root cause, and if the root cause is not a symptom of a deeper issue in the codebase. This can help prevent similar issues from occurring in the future and improve the overall quality of the codebase.

By following this process, you can effectively debug issues in the codebase, identify the root cause of problems, and provide detailed explanations of the debugging process and solutions implemented to resolve the issues. This skill is essential for maintaining a high-quality codebase and ensuring that any bugs or issues are promptly addressed and resolved.

## Evals
To evaluate the effectiveness of this skill, you can use the following criteria:
- Accuracy: The ability to correctly identify the root cause of the issue and provide a valid solution.
- Thoroughness: The depth of analysis and investigation conducted to identify the issue, including the consideration of potential hidden issues and the critical analysis of the root cause.
- Clarity: The ability to clearly explain the debugging process, the steps taken to identify the issue, and the solution implemented to resolve the problem in a way that is understandable to users and stakeholders.
- Problem-solving skills: The ability to effectively troubleshoot and resolve issues in the codebase, demonstrating strong problem-solving skills and a systematic approach to debugging.

By using these criteria to evaluate the debugging process, you can ensure that the skill is effectively applied and that issues in the codebase are thoroughly investigated and resolved in a clear and accurate manner.
